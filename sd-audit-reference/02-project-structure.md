## Naming conventions (authoritative)

Pulled from `CLAUDE.md` and confirmed against source.

| Concept | Pattern | Example |
|---|---|---|
| BLoC class | `{Feature}Bloc` | `LoginBloc`, `AuditBloc` |
| Event class | `{Action}Event` (in `*_event.dart`, `part of` the bloc file) | `LoginUserEvent`, `AuditButtonPressedEvent` |
| State class | `{Desc}State` (in `*_state.dart`, `part of` the bloc file) | `LoginLoadingState`, `AuditErrorState` |
| Use case | `{Feature}{Action}Usecase` | `LoginUsecase`, `AuditSaveAuditUsecase` |
| Use case method | always `call(...)` | `call(LoginParam)` |
| Repo interface | `{Feature}Repository` (abstract) | `LoginRepository` |
| Repo impl | `{Feature}RepositoryImpl extends BaseRepositoryImpl` | `LoginRepositoryImpl` |
| Data source | abstract `{Feature}DataSource` + `Impl` | `RemoteDataSources`, `RemoteDataSourceImpl` |
| Mapper | `{Entity}Mapper` with static methods | `ClientVisitMapper`, `StockMapper` |
| Mapper method | `{source}To{target}` | `visitBoxToDisplayModel`, `displayModelToVisitBox` |
| ObjectBox model | `{Entity}Box` | `ClientsModelBox`, `VisitBox`, `AuditBox` |
| Domain entity | `{Entity}Data` or `{Entity}Entity` | `UserData`, `ClientsEntity`, `VisitReportEntity` |
| Failure | `{Type}Failure` | `ServerFailure`, `NetworkFailure`, `LocaleFailure` |
| Exception | `{Type}Exception` | `ApiException` |
| Page / screen | `{Name}Screen` (or `{Name}Page` for sub-pages) | `DashboardScreen`, `AuditPage`, `StockPage` |
| Display model | `{Entity}DisplayModel` | `VisitDisplayModel`, `ProductDisplay` |
| Request param | `{Feature}{Verb}Param`, `BaseParam*` family | `OrderReportRequest`, `BaseParamWithDate`, `SetAvatarParam` |

## Where new files go

(Full recipe in [`21-feature-development-guide.md`](21-feature-development-guide.md).)

| New thing | Goes in |
|---|---|
| Use case | `lib/features/sd_audit/domain/usecases/` |
| Repository interface | `lib/features/sd_audit/domain/repositories/` |
| Repository impl | `lib/features/sd_audit/data/repositories/` |
| Remote method | new method on `RemoteDataSources` (interface + impl) |
| ObjectBox entity | `lib/db/models/`, then re-run codegen |
| Mapper | `lib/features/sd_audit/data/mapper/` |
| BLoC trio | `lib/features/sd_audit/presentation/bloc/{feature}/` |
| Page | `lib/features/sd_audit/presentation/pages/` |
| Reusable widget | `lib/features/sd_audit/presentation/widgets/{subfolder}/` |
| Translation keys | `assets/translations/{en,uz,ru}.json` |
