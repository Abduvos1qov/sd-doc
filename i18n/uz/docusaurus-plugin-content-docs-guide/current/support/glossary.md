# Lug'at

Tez-tez uchraydigan so'zlarning qisqacha ro'yxati.

| Atama | Ma'nosi |
|-------|---------|
| **Agent** | Mijozlarga tashrif buyuradigan, buyurtma oladigan, ba'zan yetkazib beradigan sotuvchi. |
| **AKB** | "Aktiv klient bazasi" — berilgan davrda (odatda oyda) kamida bitta buyurtma bergan mijozlar. |
| **Audit** | Do'konni tekshirish — javon, narx, poster fotosuratlari, ba'zan savol-javoblar. |
| **Filial** | O'z xodimi va ombori bo'lgan biznesingizning hududiy ofisi yoki bo'limi. |
| **Kassir** | Kun oxirida ekspeditorlar yig'gan naqd pulni sanab tasdiqlovchi shaxs. |
| **Kanal** | Savdo nuqtasi turi — kichik do'kon, supermarket, restoran, kiosk. Ko'pincha narx va aksiyalarni belgilaydi. |
| **Mijoz / Savdo nuqtasi** | Siz sotadigan istalgan joy: do'kon, restoran, kiosk. O'rinli almashtirib ishlatiladi. |
| **Kredit limiti** | Mijoz bir vaqtning o'zida qarzdor bo'la oladigan maksimal summa. |
| **Brak** | Mijozdan qaytgan va qayta sotib bo'lmaydigan tovar (shikastlangan, muddati o'tgan). |
| **Chegirma** | Narxning kamayishi, qat'iy summa yoki foiz shaklida. |
| **Ekspeditor** | Mashina haydab buyurtmalarni yetkazib beradigan shaxs. |
| **KPI** | "Asosiy samaradorlik ko'rsatkichi" — har bir agent yoki supervayzerni baholaydigan maqsad. |
| **Menejer** | Bir nechta supervayzerlar va butun savdo operatsiyasini nazorat qiluvchi foydalanuvchi. |
| **MML** | "Must-Match List" — siz xizmat qilayotgan har bir do'konda bo'lishi shart bo'lgan mahsulotlar to'plami. |
| **OKB** | "Umumiy klient bazasi" — jamoangiz tashrif buyurgan yoki sotgan har bir mijoz. AKB'dan doim katta. |
| **Buyurtma** | Mijozning ma'lum tovarlar uchun, kelishilgan narxlarda, tanlangan sanada yetkazib berish so'rovi. |
| **Savdo nuqtasi** | Mijozning boshqa nomi — do'kon, kiosk, restoran. |
| **Fotohisobot** | Auditlar paytida agentlar olgan suratlar kunlik to'plami. |
| **Reja** | Tashrif rejasi (qaysi kuni qaysi mijozga borish) yoki savdo rejasi (qancha sotish). |
| **Narx turi** | Nomlangan narx ro'yxati — "Chakana", "Ulgurji", "Diler". Har bir mijoz aniq bir narx turida sotib oladi. |
| **Tiklash** | Bekor qilingan buyurtmani qaytarish. |
| **RFM** | Mijozlarni **R**ecency (oxirgi xarid), **F**requency (chastota) va **M**onetary value (pul qiymati) bo'yicha tasniflash usuli. |
| **Qaytarim** | Mijoz qaytarib yuborgan tovar — qisman (ba'zi mahsulotlar) yoki to'liq (butun buyurtma). |
| **Marshrut** | Agent bir kunda tashrif buyuradigan mijozlar ro'yxati. |
| **Supervayzer** | Kichik agentlar jamoasini nazorat qiluvchi foydalanuvchi. |
| **Tara** | Mijozdan qaytishi kerak bo'lgan bo'sh quti, shisha, qadoq. |
| **Hudud / Territoriya** | Hisobotlarni bo'lish uchun ishlatiladigan geografik hudud — tuman, shahar zonasi, viloyat. |
| **Reys** | Ekspeditorning yetkazib berish kuni — rejalashtirilgan yuk, to'xtashlar ro'yxati, qaytish. |
| **Mashina qoldig'i** | Ekspeditor mashinasidagi tovar. Alohida ombor sifatida qaraladi. |
| **Tashrif** | Agentning bir mijozdagi to'xtashi. Buyurtmani, auditni, ikkalasini yoki hech birini o'z ichiga olishi mumkin. |
| **Ombor** | Qoldiq saqlanadigan jismoniy (yoki mantiqiy) joy. |
