# Каждая страница, каждая форма — полный каталог

Единый прокручиваемый справочник. В каждом разделе показан: скриншот страницы, для чего она нужна, какие на ней есть формы и действия, и на какую страницу вы переходите дальше.

Используйте поиск в правом верхнем углу (или `Ctrl+F`), чтобы найти конкретную страницу по названию.

## Как читать этот каталог

Каждая запись каталога содержит:
- **Скриншот** — то, что вы увидите, открыв адрес
- **Адрес** — прямой путь (можно добавить в закладки)
- **Что на странице** — основные поля, столбцы, кнопки действий
- **Куда дальше** — типичные следующие клики

Все скриншоты сделаны из реального демо-аккаунта. Цифры и имена в вашем аккаунте будут отличаться, но расположение элементов то же самое.

## 1. Вход и главная

### 1.1 Экран входа

Адрес: `/site/login`

![Login screen](/screens/guide/01-login-screen.png)

Что на странице:
- Поле **Логин** — обычно ваш номер телефона или назначенное имя пользователя
- Поле **Пароль**
- Чекбокс **Запомнить меня** — оставляет вас авторизованным в этом браузере
- Кнопка **Войти**
- Переключатель языка в углу (RU / UZ)

Куда дальше:
- **Войти** как супервайзер или администратор → главная панель супервайзера
- **Войти** как владелец с несколькими ролями → выбор роли, затем панель

### 1.2 Главная панель супервайзера

Адрес: `/dashboard/supervayzer`

![Supervisor home dashboard](/screens/guide/39-supervisor-dashboard-full.png)

Что на странице:
- Плитки ключевых KPI вверху: **Продажи**, **Визиты**, **АКБ** (активная клиентская база), **ОКБ** (общая клиентская база), **Долг**, **Заказы в ожидании**
- Селектор периода (Сегодня / Вчера / Неделя / Месяц)
- Полоса графика по периоду — продажи по дням в выбранном окне
- Таблица активности по агентам — по строке на каждого агента с его текущим днём

Куда дальше:
- **Клик по плитке «Продажи»** → панель продаж
- **Клик по плитке «Долг»** → финансовая панель
- **Клик по плитке «Визиты»** → отчёт по визитам
- **Клик по имени агента** → профиль агента

### 1.3 Панель продаж

Адрес: `/dashboard/sales`

![Sales dashboard](/screens/guide/34-dashboard-sales.png)

Что на странице:
- Итоги по продажам в разрезе агент / регион / товарная группа
- График сравнения «сегодня» с прошлой неделей
- Топ клиентов по сумме покупок
- Строка возвратов внизу

Куда дальше:
- **Клик по агенту на графике** → отчёт по продажам агента, предварительно отфильтрованный по этому человеку
- **Клик по товарной группе** → отчёт уровня товара

### 1.4 Финансовая панель

Адрес: `/dashboard/finans`

![Finance dashboard](/screens/guide/35-dashboard-finans.png)

Что на странице:
- Общая сумма к получению с разбивкой по срокам (менее 7 дней / 7–30 / 30+ дней)
- Сегодняшние платежи по кассам (наличные / банк / карта / Click / Payme)
- Список топ-должников — самые крупные открытые балансы

Куда дальше:
- **Клик по должнику** → страница платежей и долга клиента, отфильтрованная по этому клиенту
- **Клик по строке кассы** → очередь подтверждения платежей по этой кассе

### 1.5 Панель KPI (месячная)

Адрес: `/dashboard/kpi`

![KPI dashboard](/screens/guide/38-dashboard-kpi-full.png)

Что на странице:
- По одной строке на каждого агента
- Прогресс-бары по показателям: Продажи / АКБ / ОКБ / Визиты / Фото / MML
- Проценты плана к факту
- Цветовая разметка: зелёный = в графике, янтарный = отстаёт, красный = сильно отстаёт

Куда дальше:
- **Клик по строке агента** → профиль агента
- **Клик по заголовку показателя** → детализация этой метрики по всей команде

### 1.6 Биллинговая панель (использование лицензии)

Адрес: `/dashboard/billing`

Что на странице:
- Текущий баланс лицензии
- Активные места против приобретённых
- Дата продления
- Список последних платежей

*(Скриншот недоступен — биллинговая страница требует подключённого хоста вендора.)*

## 2. Заявки

### 2.1 Список заявок

Адрес: `/orders/list`

![Orders list](/screens/guide/03-orders-list.png)

Что на странице:
- Полоса фильтров вверху: **диапазон дат**, **статус**, **агент**, **экспедитор**, **склад**, **канал**, **клиент**, **способ оплаты**
- Кнопки действий: **Добавить**, **Накладные**, **Групповая обработка**, **Отчёты**, **Excel**
- Столбцы таблицы: №, тип, статус, агент, клиент, баланс, сумма, долг, дата заявки, дата отгрузки, дата доставки, экспедитор, склад
- Цветной индикатор статуса в начале каждой строки
- Пагинация внизу, выбор размера страницы

Куда дальше:
- **Клик по строке** → страница деталей заявки
- **Клик «+ Добавить»** → форма новой заявки
- **Клик «Накладные»** → список накладных
- **Отметить чекбоксы + «Групповая обработка»** → модальное окно массового обновления (назначить экспедитора, изменить статус и т. д.)

### 2.2 Форма новой заявки

Адрес: `/orders/addOrder`

![New order full form](/screens/guide/33-new-order-empty.png)

Что на странице:
- Верхний блок: выбор **клиента**, выпадающий список **агентов**, поле **даты**, выпадающий список **склада**, выпадающий список **типа цены**, выпадающий список **способа оплаты**
- Таблица товаров: поиск по штрихкоду или названию → количество → цена → скидка → итог по строке
- Кнопка добавления строки под таблицей товаров
- Строка итогов внизу: подытог, НДС, скидка, общая сумма
- Поле комментариев или заметок
- Кнопки **Сохранить** и **Отмена**

Куда дальше:
- **Клик по полю клиента** → открывается выбор клиента
  - ![Client picker](/screens/guide/40-client-picker.png)
  - Список с поиском, 10 строк на страницу
  - Поиск по имени, телефону или ИНН
  - ![Client picker filtered](/screens/guide/41-client-picker-search.png)
- **Сохранить** → возврат к списку заявок с новой заявкой сверху

### 2.3 Отказы и возвраты по заявкам

Адрес: `/orders/rejects`

![Order rejects](/screens/guide/25-orders-rejects.png)

Что на странице:
- Список заявок, от которых отказался экспедитор или клиент
- Столбец с причиной (нет на складе, неверный товар, разногласия по цене, клиент отсутствует и т. п.)
- Действие: **Восстановить** для возврата в очередь сборки

### 2.4 Восстановление заявок

Адрес: `/orders/recovery`

![Order recovery](/screens/guide/26-orders-recovery.png)

Что на странице:
- Заявки, которые были отменены или автоматически архивированы, но могут быть восстановлены
- Столбец даты отмены
- Отметить строки + **Восстановить**, чтобы вернуть их

### 2.5 Активные рейсы

Адрес: `/orders/view/trips`

![Live trips](/screens/guide/20-trips-view.png)

Что на странице:
- По одной строке на активный рейс экспедитора
- Машина / водитель / название маршрута
- Запланированные остановки против выполненных
- Текущее местоположение (последний GPS-пинг)
- Расчётное время завершения

Куда дальше:
- **Клик по рейсу** → детали рейса со статусом по каждой остановке

## 3. Клиенты

![Clients list](/screens/guide/05-clients-list.png)

Что на странице:
- Верхняя строка действий: **Добавить клиента**, **Импорт** (импорт из Excel), **Экспорт**, **На карте**
- Ссылка **Фильтры** раскрывает панель фильтров:
  - ![Clients filter panel](/screens/guide/45-clients-filter-panel.png)
  - Регион / канал / сегмент / агент / признак активности / признак долга
- Столбцы таблицы: имя, тип, регион, адрес, телефон, агент, последний визит, баланс
- Пагинация внизу

Куда дальше:
- **Клик «+ Добавить клиента»** → форма нового клиента (или агенты создают клиента в мобильном приложении во время визита)

  - ![Clients import](/screens/guide/32-clients-import.png)
  - Скачать шаблон → заполнить → загрузить → предпросмотр → подтвердить
- **Клик по строке** → профиль клиента (история, долг, фотографии, визиты)

### 3.2 Платежи и долг клиента

Адрес: `/clients/finans`

![Client payments](/screens/guide/13-client-payments.png)

Что на странице:
- Полоса фильтров клиент / агент / период
- Столбцы: клиент, общий долг, просрочка, дата последнего платежа, сумма последнего платежа, дней с тех пор
- Сортировка по сроку долга, по региону, по агенту
- Кнопка массовой SMS-рассылки

Куда дальше:
- **Клик по клиенту** → история платежей клиента
- **Массовый выбор + SMS** → страница SMS-рассылки, заранее загруженная выбранными получателями

### 3.3 Клиенты на карте

Адрес: `/clients/view/clientMap`

![Clients on map](/screens/guide/48-clients-on-map.png)

Что на странице:

- Каждая метка = один клиент
- Цвет метки по статусу (активный / неактивный / должник / без визита в этом месяце)
- Боковая панель фильтров: агент, регион, сегмент
- Клик по метке → мини-карточка с именем клиента, телефоном, агентом

### 3.4 Планирование маршрута агента

Адрес: `/clients/agentRoute`

![Agent route](/screens/guide/49-agent-route.png)

Что на странице:
- Выпадающий список агента вверху
- Карта с закреплёнными за агентом клиентами
- Список остановок слева с возможностью изменения порядка перетаскиванием
- Вкладки дней недели (Пн / Вт / Ср / Чт / Пт / Сб)
- Кнопка сохранения плана

### 3.5 История изменений визитов

Адрес: `/report/visitingHistory`

![Visit history](/screens/guide/50-visit-history.png)

Что на странице:
- Журнал аудита по каждому изменению визита
- Кто / когда / что изменил
- Полезно для разбора спорных ситуаций («агент говорит, что был, а в системе — нет»)

## Общие UI-паттерны

Эти виджеты ведут себя одинаково везде в CRM. Изучите их один раз.

### Поле поиска (в правом верхнем углу каждой страницы со списком)
- Поиск подстроки по видимым столбцам
- Живая фильтрация по мере ввода — Enter нажимать не нужно
- Нажмите `Esc`, чтобы очистить

### Полоса фильтров (под заголовком страницы)
- Выпадающие списки с множественным выбором
- Фильтры комбинируются друг с другом — выберите агента И статус И дату
- ![Status filter dropdown example](/screens/guide/44-status-filter-dropdown.png)

### Выбор диапазона дат
- ![Date range picker](/screens/guide/42-date-range-picker.png)
- Двухмесячный календарь открывается при клике на поле даты
- Быстрые ярлыки: Сегодня / Вчера / Неделя / Месяц / Квартал
- Выпадающий список типа даты (Дата заявки / Дата отгрузки / Дата доставки)
  - ![Date type dropdown](/screens/guide/43-date-type-dropdown.png)

### «Сбросить фильтр»
Всегда в правом конце полосы фильтров. Один клик очищает всё выбранное.

### Экспорт в Excel
На каждой странице со списком есть кнопка Excel — экспортирует именно то, что вы видите (текущий фильтр, текущая сортировка, все строки на всех страницах).

### Пагинация и размер страницы
В правом нижнем углу каждой таблицы. Размер страницы по умолчанию — 25; поднимите до 100, если много прокручиваете. Выбранный размер запоминается для каждой страницы.

### Массовые действия
На каждой странице со списком есть чекбоксы строк. Отметьте строки → внизу появляется панель действий с доступными операциями (назначить, изменить статус, отправить SMS, удалить и т. д.).

### Метки статусов
Цветные скруглённые ярлыки. Цветовой код одинаков по всей CRM:
- Серый = черновик / новый
- Синий = в работе
- Зелёный = выполнено / оплачено / подтверждено
- Янтарный = на удержании / ожидает подтверждения
- Красный = отменено / отклонено / просрочено
