# Глоссарий

Короткий список слов, которые встретятся вам чаще всего.

| Термин | Что означает |
|------|---------------|
| **Агент** | Сотрудник отдела продаж: посещает клиентов, принимает заявки, иногда сам же доставляет. |
| **АКБ** | «Активная клиентская база» — клиенты, сделавшие хотя бы одну заявку за период (обычно за месяц). |
| **Аудит** | Проверка в магазине — фото полок, цены, постеры, иногда вопросы анкеты. |
| **Филиал** | Региональный офис или подразделение компании со своим штатом и складом. |
| **Кассир** | Сотрудник, который пересчитывает и подтверждает наличные, собранные экспедиторами в конце дня. |
| **Канал** | Тип точки — небольшой магазин, супермаркет, ресторан, киоск. Часто определяет цену и акции. |
| **Клиент / торговая точка** | Любое место, куда вы продаёте: магазин, ресторан, киоск. Понятия взаимозаменяемы. |
| **Кредитный лимит** | Максимальная сумма, которую клиент может вам быть должен одновременно. |
| **Брак** | Товар, вернувшийся от клиента и не подлежащий перепродаже (повреждён, просрочен). |
| **Скидка** | Снижение цены — фиксированное или в процентах. |
| **Экспедитор** | Сотрудник, который водит фургон и доставляет заявки. |
| **KPI** | Key Performance Indicator — показатель, по которому оценивают агента или супервайзера. |
| **Менеджер** | Пользователь, который курирует нескольких супервайзеров и весь процесс продаж. |
| **MML** | Must-Match List — набор товаров, которые должны быть в каждом обслуживаемом магазине. |
| **ОКБ** | «Общая клиентская база» — все клиенты, к которым команда заходила или продавала. Всегда больше АКБ. |
| **Заявка** | Запрос клиента на конкретный товар по согласованным ценам с доставкой в выбранную дату. |
| **Торговая точка** | Другое слово для клиента — магазин, киоск, ресторан. |
| **Фотоотчёт** | Ежедневная подборка фото, сделанных агентами во время аудитов. |
| **План** | Либо план визитов (к кому ехать в какой день), либо план продаж (сколько продать). |
| **Тип цены** | Именованный прайс-лист — «Розница», «Опт», «Дилер». Каждый клиент покупает по одному типу цены. |
| **Восстановление** | Возвращение к жизни отменённой заявки. |
| **RFM** | Способ классификации клиентов по **R**ecency (когда покупал в последний раз), **F**requency (как часто) и **M**onetary value (на какую сумму). |
| **Возврат** | Товар, возвращённый клиентом — частично (некоторые позиции) или полностью (вся заявка). |
| **Маршрут** | Дневной список клиентов, к которым едет агент. |
| **Супервайзер** | Пользователь, который курирует небольшую команду агентов. |
| **Тара** | Пустые ящики, бутылки, упаковка, которые нужно забрать у клиента. |
| **Территория / Регион** | Географическая область для разрезов отчётов — район, зона города, регион. |
| **Рейс** | День доставок экспедитора — запланированная загрузка, список точек, возврат на склад. |
| **Машина** | Товар, который сейчас находится на машине экспедитора. Считается отдельным складом. |
| **Визит** | Заход агента к одному клиенту. Может включать заявку, аудит, и то и другое или ничего из этого. |
| **Склад** | Физическое (или логическое) место, где хранится товар. |
