# Дашборд с первого взгляда

Дашборд — это страница, которая открывается после входа. Это самая используемая страница в SalesDoctor: все важные показатели за сегодня собраны здесь.

## Шаг 1 — Откройте дашборд

Кликните на **логотип SalesDoctor** (слева сверху) с любой страницы, чтобы вернуться сюда, или просто откройте `/dashboard/supervayzer`.

![Полный вид дашборда](/screens/guide/02-dashboard-home.png)

## Шаг 2 — Верхняя панель

Сверху расположены:

- **Логотип / Главная** (слева сверху) — возврат на эту страницу
- **Колокольчик уведомлений** — новые заявки, завершённые доставки, запросы на согласование
- **Меню вашего аккаунта** (справа сверху) — смена языка, смена пароля, выход

## Шаг 3 — Левое меню

Вертикальное меню слева — список всех разделов, в которые у вас есть доступ. Стандартный набор для менеджера или администратора:

- **Планы** — планирование визитов и продаж
- **Заявки** — продажи и возвраты
- **Склад** — остатки, поступления, перемещения
- **Маркировка** — соответствие требованиям ЦРПТ и ЭДО
- **Клиенты** — база клиентов
- **Команда** — аудиторы, агенты, супервайзеры, экспедиторы
- **Аудит 2** — мерчандайзинг-аудит
- **Настройки** — цены, валюты, параметры

Если какой-то пункт меню отсутствует — обычно это значит, что он не нужен вашей роли.

## Шаг 4 — KPI-плитки по центру

Каждая плитка в основной области — это число за сегодня или за выбранный период:

- **Продажи за день** — общая сумма всех заявок за сегодня
- **Визиты** — завершённые визиты агентов
- **АКБ** — активная клиентская база (клиенты, которые заказали в этом месяце)
- **ОКБ** — общая клиентская база (все клиенты, которых обслуживает ваша команда)
- **Долг** — общая сумма задолженности клиентов
- **Заявки в ожидании** — новые заявки, ещё не отгруженные

Кликните по любой плитке, чтобы открыть детальный отчёт за этим числом.

## Шаг 5 — Сменить период

Сверху дашборда есть выбор периода — можно сравнить сегодня со вчера, с прошлой неделей или месяцем. Удобно для отслеживания трендов.

## Советы

- **Сохраните страницу в закладки** браузера для быстрого доступа.
- **Кликните по имени агента** в супервайзерской выкладке, чтобы увидеть его день в деталях.
- **Открывайте в новой вкладке** (`Ctrl+Click` или `Cmd+Click`), чтобы дашборд оставался в одной вкладке, пока вы работаете в другой.
