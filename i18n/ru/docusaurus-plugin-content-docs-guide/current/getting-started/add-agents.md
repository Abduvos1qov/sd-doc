# Добавьте торговых агентов

Торговые **агенты** — это люди, которые ездят к клиентам и принимают заявки. У каждого агента должен быть свой логин, чтобы визиты и заявки фиксировались на правильного человека.

## Шаг 1 — Откройте список агентов

В меню выберите **Команда → Агенты** или откройте `/agents/agent`:

![Список агентов — верх страницы с кнопками действий](/screens/guide/07-agents-list.webp)

Список показывает всех агентов вашей команды: телефон, супервайзер и статус активности.

## Шаг 2 — Нажмите «Добавить агента»

Кнопка **+ Добавить агента** в правом верхнем углу списка открывает форму:

![Форма добавления агента со всеми полями](/screens/guide/29-add-agent-form.webp)

## Шаг 3 — Заполните форму

| Поле | Что вводить |
|-------|---------------|
| **Логин** | Короткий логин (например, `agent.askar`) — агент будет вводить его в мобильном приложении |
| **Пароль** | Пароль, который вы передадите агенту |
| **ФИО** | Полное имя агента в том виде, в котором оно должно отображаться в документах |
| **Телефон** | Рабочий мобильный номер — для SMS и восстановления пароля |
| **Филиал** | К какому филиалу / офису относится агент |
| **Супервайзер** | Кто курирует этого агента (можно изменить позже) |
| **Активен** | Оставьте включённым. Выключите позже, если агент уходит из команды. |

## Шаг 4 — Сохраните

Нажмите **Сохранить**. Агент сразу появится в списке и сможет войти в мобильное приложение с новым логином и паролем.

## Шаг 5 — Назначьте маршрут или план KPI (опционально)

Из карточки агента уже можно:

- **Назначить недельный маршрут визитов** — см. [Планирование визитов](../daily-use/plan-visits)
- **Задать KPI-цели** на месяц: продажи, АКБ, визиты — см. [Дашборд и KPI](../reports/dashboard-kpi)

## Шаг 6 — Откройте профиль агента

Нажмите на имя агента в списке, чтобы открыть его профиль:

![Карточка агента — вкладки KPI, маршрут, история](/screens/guide/47-agent-detail.webp)

Здесь вы можете:
- Изменить телефон, логин, привязку к супервайзеру
- Открыть вкладку **KPI** и задать цели на месяц
- Открыть вкладку **Маршрут** и настроить план визитов
- Посмотреть последнюю синхронизацию и устройство

## Если агент уходит из команды

Не удаляйте аккаунт — это сотрёт всю историю визитов и заявок. Вместо этого:

1. Откройте карточку агента.
2. Снимите галочку **Активен** и сохраните.

Агент больше не сможет войти в систему, но все его прошлые данные останутся видны в отчётах.

:::tip Один агент — один логин
У каждого агента должен быть свой логин. Если двое работают под одним — заявки записываются не на того человека.
:::
