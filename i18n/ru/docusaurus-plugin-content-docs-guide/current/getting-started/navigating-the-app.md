# Как ориентироваться в системе

SalesDoctor собирает все функции в небольшое число понятных меню. Как только вы запомните, где находится каждое из них, вы всегда будете в двух кликах от нужной страницы.

## Шаг 1 — Верхняя панель

Сверху на каждой странице:

![Дашборд SalesDoctor с видимой верхней панелью](/screens/guide/02-dashboard-home.png)

- **Логотип (слева сверху)** — возврат на главный дашборд
- **Колокольчик уведомлений** — новые заявки, завершённые доставки, запросы на согласование
- **Меню аккаунта (справа сверху)** — язык, пароль, выход

## Шаг 2 — Боковое меню

Левое меню — список всех основных разделов:

| Меню | Что внутри | Прямая ссылка |
|------|---------------|-----------|
| **Планы** | Планирование визитов и продаж | `/planning/monthly` |
| **Заявки** | Продажи, возвраты, доставки | `/orders/list` |
| **Склад** | Склады, остатки, поступления | `/warehouse/list` |
| **Маркировка** | Соответствие ЦРПТ и ЭДО | `/markirovka/view/incomingInvoices` |
| **Клиенты** | База клиентов, платежи, долги | `/clients/client` |
| **Команда** | Аудиторы, супервайзеры, экспедиторы, пользователи | `/team/auditor` |
| **Аудит 2** | Мерчандайзинг-аудит | `/audit/photoReport` |
| **Настройки** | Цены, валюты, филиалы | `/settings/diler` |

:::tip Если каких-то пунктов меню нет
Обычно это значит, что они не нужны вашей роли. Администратор может выдать доступ через **Настройки → Доступ**.
:::

## Шаг 3 — Прямые ссылки

У каждой страницы стабильный URL — сохраняйте часто используемые отчёты в закладки. Самые популярные:

| URL | Что открывает |
|-----|---------------|
| `/dashboard/supervayzer` | Сегодняшний дашборд команды |
| `/dashboard/kpi` | Месячный KPI-дашборд |
| `/orders/list` | Список заявок |
| `/orders/addOrder` | Форма создания заявки |
| `/clients/client` | Список клиентов |
| `/clients/finans` | Платежи и долги клиентов |
| `/report/agent` | Отчёт по продажам по агенту |
| `/report/customer` | Отчёт по продажам по клиенту |

## Шаг 4 — Открыть в новой вкладке

`Ctrl + Click` (или `Cmd + Click` на Mac) на любом пункте меню откроет его в новой вкладке браузера. Удобно, когда хочется держать дашборд в одной вкладке, а в другой работать с отчётом.

## Шаг 5 — Сменить язык

Откройте меню аккаунта (справа сверху) → **Язык**. Выбор сохранится до следующего входа. Доступны: Русский, O'zbekcha, English.

## Поиск, фильтры и выбор записей

Каждая страница со списком в SalesDoctor построена по одной и той же трёхслойной схеме.

**1. Поле поиска справа сверху** — введите несколько символов, и таблица сразу сужается. Работает по любой текстовой колонке (название клиента, имя агента, логин, название товара, номер заявки).

**2. Полоса фильтров под заголовком** — выпадающие списки с множественным выбором. Клик по выпадающему списку открывает список с галочками; выбирайте одно или несколько значений. Таблица обновляется сразу.

![Развернутая панель фильтров на списке клиентов](/screens/guide/45-clients-filter-panel.png)

**3. Диалог-пикер внутри формы** — когда форма требует выбрать существующую запись (клиента, товар, склад), открывается постраничная таблица со своим собственным поиском:

![Пикер клиентов — постраничная таблица с поиском](/screens/guide/40-client-picker.png)

Несколько правил:

- Поиск работает по **подстроке** — `мага` находит *Магазин Юлдуз*, *Магистраль*, *Гранд-Мага*.
- Фильтры **накладываются** — выбор Регион = Ташкент И Канал = супермаркет сужает выборку до точек, подходящих под оба условия.
- Состояние фильтров хранится в URL — скопируйте URL, и коллега получит ровно ваш вид.
- **Сбросить фильтр** очищает все фильтры одним нажатием.

## Советы

- **Стабильные URL** — сохраняйте часто используемые страницы в закладки.
- **Кнопка «Назад» в браузере** работает везде — отдельная кнопка «назад» в приложении не нужна.
- **Обновляйте после долгого простоя** — если данные кажутся устаревшими, нажмите `F5`.
