# Настройте склады

**Склад** — это любое место, где хранится товар: центральный склад, филиальная точка, фургон экспедитора. Каждая единица товара в любой момент находится ровно на одном складе.

## Шаг 1 — Откройте список складов

В меню выберите **Склад → Склады** или откройте `/warehouse/list`:

![Список складов — все филиалы и типы](/screens/guide/08-warehouses-list.webp)

Список показывает каждый склад: его тип, ответственный сотрудник и текущая стоимость остатков.

## Шаг 2 — Решите, какие типы нужны

В большинстве дистрибуторских компаний обычно есть такие:

| Тип | Пример названия | Назначение |
|------|--------------|---------|
| **Основной** | «Центральный склад» | Принимает товар от поставщиков |
| **Филиал** | «Ташкентский филиал» | Остатки в региональном офисе |
| **Машина** | «Машина №07» | То, что везёт экспедитор |
| **Брак** | «Возвраты / повреждения» | Товар, который вернулся и не подлежит перепродаже |

## Шаг 3 — Нажмите «Добавить склад»

Нажмите **+ Добавить** в правом верхнем углу.

## Шаг 4 — Заполните форму

| Поле | Что вводить |
|-------|---------------|
| **Название** | Понятное команде название |
| **Тип** | Основной / Филиал / Машина / Брак |
| **Ответственный** | Сотрудник, который может подписывать поступления и перемещения |
| **Адрес** | Физический адрес (или «Машина №07» для транспорта) |

## Шаг 5 — Сохраните

Нажмите **Сохранить**. Склад сразу появится в списке. Теперь можно завести на него товар через **Поступления** — об этом в следующей главе.

## Что можно делать с каждым складом

Кликните по строке склада, чтобы открыть карточку:

- **Текущие остатки** — каждый товар, количество, стоимость
- **Движения** — все поступления, продажи, перемещения на другие склады
- **Инвентаризации** — сравнение того, что лежит на полках, с тем, что показывает система

## Советы

- **Одного основного склада достаточно** для старта — остальные добавите позже.
- **Отдельный склад «Брак»** сильно упрощает сведение остатков в конце месяца.
- **Не меняйте тип склада** после того, как начали им пользоваться — лучше создайте новый.
