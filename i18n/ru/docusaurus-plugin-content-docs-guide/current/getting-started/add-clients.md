# Добавьте клиентов

**Клиент** в SalesDoctor — это любая точка, куда вы продаёте товар: магазин, ресторан, киоск, супермаркет. Каждая заявка, долг, визит и KPI привязаны к клиенту, поэтому этот список — сердце вашей системы.

## Шаг 1 — Откройте список клиентов

В меню выберите **Клиенты → Все клиенты** или откройте `/clients/client`:

![Список клиентов — поиск, фильтры и таблица](/screens/guide/05-clients-list.webp)

Список показывает всех клиентов: телефон, адрес, канал и текущий баланс.

## Шаг 2 — Сначала найдите клиента

Прежде чем создавать дубль, поищите по названию или телефону в строке поиска сверху. Если клиент уже есть — кликните по строке, чтобы открыть и отредактировать.

## Шаг 3 — Нажмите «Добавить»

Нажмите кнопку **+ Добавить** в правом верхнем углу.

## Шаг 4 — Заполните основные данные

| Поле | Что вводить |
|-------|---------------|
| **Название** | Официальное название магазина или организации |
| **Телефон** | Рабочий номер (для SMS и подтверждения заявок) |
| **Адрес** | Адрес, который агент сможет прочитать на двери |
| **Регион / Территория** | Географическая принадлежность |
| **Канал** | Тип точки — магазин, супермаркет, ресторан, кафе |
| **Тип цены** | По какому прайс-листу покупает этот клиент |
| **Агент** | Агент, который посещает этого клиента |

## Шаг 5 — Координаты (рекомендуется)

Если агент сейчас в магазине, **мобильное приложение** ловит GPS-координаты одним нажатием. С веба можно вставить широту/долготу или кликнуть по карте.

Точные координаты позволяют потом автоматически проверять визиты.

## Шаг 6 — Условия продажи (опционально)

- **Тип оплаты** — наличные при доставке, в кредит или перевод на счёт
- **Кредитный лимит** — максимальная сумма, которую клиент может вам должен

## Шаг 7 — Сохраните

Нажмите **Сохранить**. Клиент сразу появится в списке и будет доступен для новых заявок.

## Массовая загрузка клиентов

Если у вас уже есть список в Excel — используйте страницу импорта по адресу `/clients/client/import`:

![Импорт клиентов из Excel](/screens/guide/32-clients-import.webp)

Скачайте шаблон, заполните его и загрузите обратно — каждая строка станет клиентом за один проход.

## Когда клиентов добавляют в полях

Большинство клиентов агенты заводят прямо во время визитов. Агент нажимает **+ Добавить клиента** в телефоне, координаты ловятся автоматически, и новый клиент появляется в офисе за несколько секунд.

:::tip Аккуратные названия
«Магазин 'Yulduz', ул. Навои 10» читается лучше, чем «MAGAZIN YULDUZ NAVOI 10». Чем чище название, тем легче искать.
:::
