# Добавьте супервайзеров

**Супервайзер** курирует группу агентов. Он видит прогресс команды в реальном времени на дашборде, согласовывает спецпрайсы и проверяет ежедневные отчёты.

## Шаг 1 — Откройте список супервайзеров

В меню выберите **Команда → Супервайзеры** или откройте `/team/supervisor`:

![Список супервайзеров](/screens/guide/17-supervisors-list.webp)

Список показывает каждого супервайзера с телефоном, филиалом и подчинёнными агентами.

## Шаг 2 — Нажмите «Добавить супервайзера»

Нажмите **+ Добавить** в правом верхнем углу. Откроется форма по адресу `/team/supervisor/create`:

![Форма добавления супервайзера](/screens/guide/30-add-supervisor-form.webp)

## Шаг 3 — Заполните форму

| Поле | Что вводить |
|-------|---------------|
| **Логин** | Короткий логин (например, `sup.olim`) |
| **Пароль** | Пароль, который вы передадите ему |
| **ФИО** | Полное имя |
| **Телефон** | Рабочий мобильный номер |
| **Филиал** | Филиал, к которому относится |
| **Агенты** | Отметьте агентов, которые будут подчиняться этому супервайзеру |

## Шаг 4 — Сохраните

Нажмите **Сохранить**. Супервайзер сразу сможет войти в то же веб-приложение.

## Что может супервайзер

| Действие | Где |
|--------|-------|
| Следить за прогрессом команды в реальном времени | Дашборд |
| Согласовывать спецпрайсы | Алерт по заявкам в ожидании |
| Проверять ежедневные отчёты | Отчёты → По агенту |
| Смотреть фотографии с визитов | Аудит → Фотоотчёт |
| Отслеживать прогресс KPI агентов | Дашборд / Отчёт по KPI |

## Шаг 5 — Перевод агента к другому супервайзеру

Чтобы перевести агента:

1. Откройте профиль **нового** супервайзера
2. Найдите агента в списке **Агенты**
3. Поставьте галочку и сохраните

Агент сразу начинает подчиняться новому супервайзеру. История прошлых периодов остаётся за тем, кто курировал агента в то время.

:::tip Один супервайзер на агента
У агента в каждый момент времени ровно один супервайзер. Если нужно, чтобы за командой следили двое — дайте им роль **Менеджер**: менеджеры видят всех агентов сразу.
:::
