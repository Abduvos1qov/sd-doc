# Дашборд и KPI

Дашборд — пульс вашего бизнеса: все важные показатели за день в одном месте. После пары недель работы дашборд становится главным экраном для понимания, как идут дела. **Каждая плитка кликабельна** и открывает детальный отчёт.

## Шаг 1 — Откройте главный дашборд

Из меню нажмите **логотип** (слева сверху) или откройте `/dashboard/supervayzer`:

![Главный дашборд супервайзера — плитки KPI и таблица агентов](/screens/guide/39-supervisor-dashboard-full.webp)

Страница состоит из трёх зон:

1. **Верхние плитки** — самые важные сегодняшние цифры
2. **Графики посередине** — динамика за период (визиты, продажи, возвраты)
3. **Таблица агентов внизу** — прогресс каждого агента за день

## Шаг 2 — Раскройте «Продажи»

Нажмите на плитку **Продажи** (или откройте `/dashboard/sales`). Открывается дашборд продаж:

![Раскрытие продаж — по агенту, по региону, по группе товаров](/screens/guide/34-dashboard-sales.webp)

Вы увидите:
- Продажи в разрезе **агента**, **региона**, **группы товаров**
- **Полоса графиков** — сегодня vs тот же день прошлой недели
- **Топ клиентов** по обороту
- **Возвраты** отдельной полоской — что вернулось не менее важно, чем что ушло

## Шаг 3 — Раскройте «Финансы» (долг)

Нажмите на плитку **Долг** (или откройте `/dashboard/finans`):

![Раскрытие финансов — задолженности, поступления, итоги касс](/screens/guide/35-dashboard-finans.webp)

На этом экране собрано:
- **Общая задолженность** — сколько вам должны клиенты, с разбивкой по сроку
- **Поступления за сегодня** — по кассе, по способу оплаты
- **Возрастные корзины долга** — до 7 дней, 7–30, 30+
- **Топ должников** по сумме — ваш список звонков на сегодня

Клик по любой строке открывает полную историю расчётов с клиентом.

## Шаг 4 — Раскройте «Визиты»

Нажмите на плитку **Визиты** или откройте `/report/visit`:

![Отчёт по визитам — карта покрытия по агенту](/screens/guide/37-report-visit.webp)

Отчёт по визитам отвечает сразу на два вопроса:
- **Охват** — какую долю запланированных клиентов агент действительно посетил
- **Качество** — сколько простоял, что зафиксировал (заявка, фото), кого пропустил (с причиной)

## Шаг 5 — Откройте месячный дашборд KPI

Чтобы увидеть всю команду за месяц, откройте `/dashboard/kpi`:

![Месячный дашборд KPI — прогресс-бары по каждому агенту](/screens/guide/38-dashboard-kpi-full.webp)

Это лента прогресса агентов за месяц. У каждого агента — своя строка с прогресс-барами по каждому показателю.

## Шаг 6 — Прочитайте каждый показатель

Типовые KPI на дашборде:

| KPI | Что измеряется |
|-----|----------------|
| **План продаж** | Какую сумму в заявках агент должен сделать за месяц |
| **АКБ** | Сколько активных клиентов агент удерживает |
| **ОКБ** | Сколько клиентов агент посетил вообще |
| **План визитов** | Сколько визитов в день или в месяц |
| **MML** | «Must-Match List» — товары, которые должны быть в каждом магазине |
| **Фотоплан** | Сколько аудит-фото на визит |

Двух-трёх показателей достаточно — больше размывает фокус.

## Шаг 7 — Поставьте цель агенту

1. Откройте профиль агента (**Команда → Агенты** → клик по имени)
2. Перейдите во вкладку **KPI**
3. Для каждого показателя укажите **цель на месяц**
4. Нажмите **Сохранить**

Агент тут же видит свою цель на главном экране мобильного приложения — прогресс-бар заполняется по ходу месяца.

## Расчёт бонуса по итогам месяца

Если у вас оплата бонуса завязана на KPI:

1. В последний рабочий день месяца значения KPI фиксируются
2. Бонус каждого агента считается против ваших целей
3. Результат появляется в отчёте KPI — финансы берут его в зарплату

## Подсказки

- **Берите KPI, которые агент может контролировать** — наказывать за низкие продажи, когда товара постоянно нет на складе, демотивирует.
- **2–3 KPI — потолок** — больше пяти расфокусирует.
- **Покажите KPI на главном экране телефона агента** — одна только видимость уже меняет поведение.
- **Кликайте всё подряд** — каждая цифра на дашборде ведёт в детальный отчёт. Если хочется понять, из чего сложилось число — кликните.
