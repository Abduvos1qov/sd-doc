# Продажи и долги

Два самых востребованных отчёта отвечают на два простых вопроса: **сколько мы продали?** и **кто нам должен?**

## Сколько мы продали?

### Шаг 1 — Откройте отчёт по агентам

В меню выберите **Отчёты → По агентам** или откройте `/report/agent`:

![Отчёт продаж по агентам — фильтры и таблица](/screens/guide/12-report-agent.webp)

### Шаг 2 — Выберите период

Верхняя панель фильтров:

- **Период** — диапазон дат (сегодня / неделя / месяц / произвольный)
- **Филиал** — сузить до одного офиса
- **Супервайзер** — сузить до одной команды
- **Категория клиента** — фильтр A/B/C

Полоса фильтров на странице отчёта по агентам выглядит так:

![Полоса фильтров отчёта — полный набор доступных фильтров](/screens/guide/46-report-filter-strip.webp)

Фильтры работают вместе — каждый дополнительно сужает отчёт. После их изменения нажмите **Сформировать**, чтобы обновить данные.

### Шаг 3 — Нажмите «Сформировать»

Таблица обновится — по одной строке на агента. Колонки:

- Общая сумма продаж
- Количество заявок
- Количество посещённых клиентов (ОКБ)
- Количество клиентов с заявкой (АКБ)
- Средний чек

### Шаг 4 — Углубитесь в одного агента

Кликните по строке агента, чтобы увидеть его заявки, визиты и фото за период.

### Шаг 5 — Выгрузка в Excel

Кнопка **Excel** справа сверху выгружает таблицу как есть — те же колонки, те же фильтры.

## Кто нам должен?

### Шаг 1 — Откройте оплаты клиентов

В меню выберите **Клиенты → Оплаты** или откройте `/clients/finans`:

![Оплаты и долги клиентов](/screens/guide/13-client-payments.webp)

Вы увидите каждого клиента с текущим балансом — положительный означает долг, ноль означает чистый счёт.

### Шаг 2 — Фильтр по возрасту долга

Группы по сроку сверху позволяют сфокусироваться:

- **Менее 7 дней** — свежий долг, обычно легко вернуть
- **7–30 дней** — нужен телефонный звонок
- **Старше 30 дней** — нужна эскалация

### Шаг 3 — Зафиксируйте оплату

Когда клиент платит (наличными, переводом или лично):

1. Кликните по строке клиента, чтобы открыть карточку
2. Нажмите **+ Добавить оплату**
3. Введите:
   - **Сумма**
   - **Тип** (наличные / карта / банковский перевод)
   - **Дата**
   - **Касса** — ваш кассовый узел
4. Нажмите **Сохранить**

Долг тут же уменьшается. Если наличные принёс экспедитор, в конце дня их подтверждает кассир.

### Шаг 4 — Подтвердите наличные от экспедиторов (для кассира)

Если вы принимаете наличные при доставке:

1. Откройте **Платежи → На утверждение**
2. Каждая строка — наличная оплата, которую экспедитор зафиксировал сегодня
3. Пересчитайте деньги, поставьте галочку **Утверждено**
4. Платёж появится в отчёте по долгам как закрытый

## Советы

- **Запускайте отчёт по долгам еженедельно** — мелкие долги до 7 дней закрываются легко, старше 30 дней редко возвращаются полностью.
- **Всегда записывайте причину** при списании долга — когда финансы спросят позже, комментарий спасёт.
- **Используйте возрастные группы** для приоритизации звонков — начинайте с группы 30+ дней.
