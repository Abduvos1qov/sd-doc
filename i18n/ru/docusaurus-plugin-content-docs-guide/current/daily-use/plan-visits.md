# Планирование визитов агентов

**План визитов** говорит каждому агенту, к каким клиентам ехать в какой день недели. Когда план настроен, каждое утро ваша команда открывает мобильное приложение и видит готовый маршрут.

## Шаг 1 — Откройте месячный планировщик

В меню выберите **Планы → Месяц** или откройте `/planning/monthly`:

![Месячный планировщик визитов — сетка календаря](/screens/guide/11-planning-monthly.webp)

Сетка показывает каждый рабочий день месяца с количеством запланированных визитов по агентам.

## Шаг 2 — Выберите агента (или день)

Два способа начать планирование:

- **По агенту** — кликните по строке агента, чтобы спланировать его неделю целиком
- **По дню** — кликните по столбцу дня, чтобы спланировать этот день всей команде

## Шаг 3 — Добавьте клиентов в день

В ячейке агент×день нажмите **+** (или просто кликните по ячейке). Появится диалог выбора:

- **Регион / Территория** — сузить список
- **Канал** — фильтр по типу точки
- **Категория** — деление клиентов A/B/C

Отметьте нужных клиентов и нажмите **Добавить**.

## Шаг 4 — Задайте частоту

Для каждого клиента можно выбрать:

- **Каждую неделю**
- **Раз в две недели**
- **Раз в месяц**

План повторяется автоматически — настройте один раз, и он применяется на каждую неделю.

## Шаг 5 — Сохраните

Нажмите **Сохранить** сверху. План вступает в силу сразу:

- Агенты видят сегодняшних клиентов в мобильном приложении
- Супервайзеры видят прогресс на дашборде в реальном времени

## Что видит агент на телефоне

Каждое утро на главном экране агент видит запланированных на сегодня клиентов:

- В каком порядке к ним ехать (можно тянуть для переупорядочивания)
- Зелёная галочка после посещения
- Красный флажок на пропусках (с причиной: магазин закрыт, отказ, нет контакта)

## Корректировка планов на лету

План не высечен в камне. Можно:

- **Перенести визит на другой день** — перетащите клиента в нужную ячейку дня
- **Пропустить неделю** — выберите «пропустить» в строке клиента
- **Добавить разовый визит** без изменения основного плана — агент получит уведомление

## Советы

- **Реалистичные цифры**: 20–30 клиентов на агента в день — нормально для большинства каналов.
- **Группируйте по географии**, а не по алфавиту — мотаться зигзагом по городу — потеря часов.
- **Пересматривайте раз в месяц** вместе с супервайзером. Убирайте клиентов с постоянным отказом, добавляйте новых, которых открыл агент.
