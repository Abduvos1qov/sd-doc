# Создайте первую заявку

Теперь, когда у вас есть агенты, клиенты и товары, можно принять первую заявку. Заявки приходят из трёх мест: **мобильное приложение** (большинство), **веб-приложение** (как здесь) или **онлайн-портал**.

## Шаг 1 — Откройте список заявок

В меню выберите **Заявки → Список заявок** или откройте `/orders/list`:

![Список заявок — сегодняшние и недавние](/screens/guide/03-orders-list.png)

Каждый столбец фильтруется — статус, агент, клиент, дата, склад.

## Шаг 2 — Нажмите «Добавить»

Кнопка **+ Добавить** в правом верхнем углу. Вы попадёте на форму создания заявки по адресу `/orders/addOrder`:

![Форма новой заявки — полный вид от шапки до таблицы товаров](/screens/guide/33-new-order-empty.png)

Форма состоит из трёх блоков: **шапка** (клиент, агент, даты), **таблица товаров** и **строка итогов** внизу.

## Шаг 3 — Выберите клиента

Начните вводить название клиента в поле **Клиент**. Подсказки появляются после 2–3 букв. Выберите нужного.

Система автоматически подставит:

- **Тип цены** — прайс-лист для этого клиента
- **Условия оплаты**
- **Кредитный лимит**

Выбор клиента — это таблица с постраничной разбивкой. По умолчанию отображается первые 10 клиентов из всего списка:

![Выбор клиента — полная таблица всех клиентов](/screens/guide/40-client-picker.png)

Начните вводить любую часть имени клиента в поле **Поиск** в верхней части окна. Таблица сразу же сужается:

![Выбор клиента с фильтром «мага» — список сужается](/screens/guide/41-client-picker-search.png)

Кликните по строке, чтобы подтвердить выбор. Окно закрывается, и форма заявки переходит к таблице товаров.

## Шаг 4 — Добавьте товары

Для каждого товара:

1. Введите название или отсканируйте штрихкод
2. Укажите **количество**
3. **Цена** подставится из прайс-листа автоматически

Внизу формы итог обновляется по мере добавления строк.

:::tip Скидки и бонусы
Если администратор настроил скидки или акции «купи-X-получи-Y», они применяются автоматически. Скидка появится в итогах — считать ничего вручную не нужно.
:::

## Шаг 5 — Параметры доставки

- **Дата отгрузки** — когда товар должен попасть к клиенту
- **Склад** — откуда отгружаем (по умолчанию ближайший)
- **Экспедитор** — кто доставит (можно назначить позже)

## Шаг 6 — Сохраните

Нажмите **Сохранить**. Заявка переходит в статус **Новая** и сразу появляется в списке:

![Список заявок с новой заявкой сверху](/screens/guide/03-orders-list.png)

## Шаг 7 — Отслеживание заявки по этапам

В списке заявок ваша заявка проходит:

1. **Новая** — только что создана
2. **Загружена** — на машине экспедитора
3. **Доставлена** — получена клиентом
4. **Закрыта** — оплачена (или перешла в долг)

В любой момент можно кликнуть по строке и увидеть детали, фото с доставки, статус оплаты.

## Советы

- **Проверьте долг клиента** перед сохранением большой заявки — если она превышает кредитный лимит, появится красное предупреждение.
- **Не правьте цены вручную**, если этого не требуют ваши правила скидок — прайс-лист является источником истины.
- **Добавьте комментарий** для особых инструкций («звонить в задний вход», «спросить Салима»).
