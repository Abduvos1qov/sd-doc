# Отслеживание заявок в течение дня

После создания заявка проходит через понятные этапы. Понимание того, где сейчас каждая заявка, помогает ловить проблемы рано — машина к полудню ещё не загружена, клиент отказался от половины, оплата не собрана.

## Шаг 1 — Откройте список заявок

В меню выберите **Заявки → Список заявок** или откройте `/orders/list`:

![Список заявок со статусами](/screens/guide/03-orders-list.png)

Каждая строка — заявка. Колонка **Статус** показывает, на каком этапе она.

## Шаг 2 — Что означают статусы

| Статус | Значение |
|--------|---------|
| **Новая** | Только создана. Ничего ещё не отгружено. |
| **Загружена** | Товар на машине экспедитора, в пути. |
| **Доставлена** | Клиент получил товар. Оплата может быть в ожидании. |
| **Возврат частичный** | Клиент отказался от части позиций, остальное принял. |
| **Возврат полный** | Полный отказ от заявки. |
| **Отменена** | Закрыта до доставки. |

## Фильтрация списка

В верхней части списка заявок есть три рычага фильтрации.

### По диапазону дат

Кликните по полю даты, чтобы открыть двухмесячный календарь:

![Открытый выбор диапазона дат](/screens/guide/42-date-range-picker.png)

Выберите начальную и конечную даты, затем кликните в любом месте за пределами, чтобы применить.

### По типу даты

Выпадающий список слева от поля даты переключает, к какой дате применяется диапазон:

![Выпадающий список типов даты — дата заявки, дата отгрузки, дата доставки](/screens/guide/43-date-type-dropdown.png)

- **Дата заявки** — когда заявка была создана
- **Дата отгрузки** — когда товар покинул склад
- **Дата доставки** — когда клиент получил товар

### По статусу (и остальная полоса фильтров)

Полоса фильтров под заголовком содержит много выпадающих списков — статус, тип заявки, категория клиента, территория, супервайзер, агент, экспедитор, тип цены, канал, склад, категория продукта:

![Открытый выпадающий фильтр статусов заявки](/screens/guide/44-status-filter-dropdown.png)

Нажмите на любой выпадающий список, чтобы выбрать несколько значений. Таблица ниже обновляется по мере изменения фильтров.

Нажмите **Сбросить фильтр** в правом конце полосы, чтобы очистить всё сразу.

## Шаг 3 — Откройте заявку детально

Кликните по строке, чтобы открыть полную карточку:

- Все строки товаров с ценами
- Кто создал (агент, веб-пользователь или онлайн-портал)
- Кто доставляет
- Фотографии с доставки
- Статус оплаты

## Шаг 4 — Рейсы в реальном времени

Для картины по машинам откройте **Заявки → Рейсы**:

![Рейсы](/screens/guide/20-trips-view.png)

Видны все рейсы экспедиторов: точки, деньги в машине, аномалии.

## Что делать с проблемами

### Частичный отказ на месте

Когда клиент отказывается от части позиций, экспедитор фиксирует это в мобильном приложении. Система автоматически:

- Убирает отказные позиции из накладной
- Возвращает товар на ваш склад брака
- Корректирует сумму к оплате

Изменение появляется на дашборде через секунды. Отказы отфильтрованы отдельно по адресу `/orders/rejects`:

![Список отказов / возвратов](/screens/guide/25-orders-rejects.png)

### Полный отказ

Та же логика, отказ от всей заявки. Машина везёт всё обратно.

### Восстановление отменённой заявки

Если заявку отменили по ошибке, её можно восстановить через `/orders/recovery`:

![Восстановление заявок](/screens/guide/26-orders-recovery.png)

1. Найдите отменённую заявку
2. Нажмите **Восстановить**
3. Заявка возвращается в предыдущий статус, товар снова резервируется

## Шаг 5 — Закройте день

В конце дня:

- Проверьте, что ни одна заявка не осталась в статусе **Загружена** — это значит, что она не доехала
- Убедитесь, что экспедитор вернулся с правильным остатком и деньгами
- Подтвердите ожидающие платежи (см. [Продажи и долги](../reports/sales-and-debts))

## Советы

- **Не правьте доставленную заявку** без острой необходимости — это путает и клиента, и бухгалтерию.
- **Используйте поле комментария** для всего нестандартного — когда финансы спросят через неделю, комментарий спасёт.
- **Следите за повторными отказами** у одного клиента — это сигнал, что что-то не так (цена, канал, отношения).
