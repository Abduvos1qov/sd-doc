# Визиты и аудит

**Визит** — это не только заявка. Пока агент в магазине, он также может сфотографировать полки, ответить на вопросы анкеты и подтвердить цены. Всё это вместе — **аудит**, золотая жила для управления присутствием бренда в каждой торговой точке.

## Что делает агент на телефоне

| Шаг | Что происходит |
|------|--------------|
| **1. Приход в магазин** | Мобильное приложение автоматически ловит GPS и отмечает начало визита |
| **2. Принять заявку** | Выбрать товары, указать количество, цены подставляются сами |
| **3. Сфотографировать полки** | Приложение показывает ориентиры (центрировать, навести фокус) |
| **4. Фото конкретных точек** | Морозильник, касса, вход — что настроили |
| **5. Ответить на вопросы анкеты** | Да/нет, варианты ответа или короткий текст |
| **6. Подтвердить цены** в магазине | Быстрый прайс-аудит |
| **7. Нажать «Готово»** | Визит закрыт, данные уходят в офис |

Весь поток занимает 2–3 минуты на магазин.

## Шаг 1 — Откройте фотоотчёт (в офисе)

В меню выберите **Аудит → Фотоотчёт** или откройте `/audit/photoReport`:

![Фотоотчёт — все фотографии всех агентов за сегодня](/screens/guide/15-audit-photoreport.webp)

## Шаг 2 — Примените фильтры

Верхняя панель фильтров:

- **Дата** — один день или диапазон
- **Агент** — один или несколько
- **Клиент** — конкретная точка
- **Тип фото** — морозильник / полка / вход и т.д.

## Шаг 3 — Просмотрите одно фото

Кликните по фото, чтобы открыть. В режиме просмотра можно:

- **Одобрить** — фото в порядке, агент получает зачёт в KPI
- **Отклонить** — фото размытое или с не того ракурса; агент получает фидбэк в приложении, фото не засчитывается
- **Добавить комментарий** — пояснение для агента

## Шаг 4 — Замечайте тренды

Используйте ползунок периода, чтобы увидеть, как меняется выкладка во времени. На что обращать внимание:

- Активность конкурентов (новые постеры, новые холодильники)
- Сигналы дефицита (пустая полка, где должен стоять ваш товар)
- Сбой цен (магазин продаёт слишком дёшево или слишком дорого)

## Зачем нужен аудит

| Без аудита | С аудитом |
|------------------|---------------|
| Вы видите только сколько продали | Вы видите *почему* продали (или нет) |
| Изменения в маркетинге проходят мимо | Новый постер появляется в следующем фотоотчёте |
| Конкуренты тихо забирают полку | Вы замечаете это в ту же неделю |
| Споры на тему «мне такого не давали» | Фото снимает вопрос за две секунды |

## Советы

- **Начинайте с малого** — трёх-четырёх типов фото достаточно. Не требуйте 20 фото за визит; качество падает.
- **Покажите, что значит «хорошее» фото** — поделитесь с командой одним отличным фото, остальные подтянутся.
- **Используйте отклонения как фидбэк** — через неделю качество фото по команде заметно растёт.
