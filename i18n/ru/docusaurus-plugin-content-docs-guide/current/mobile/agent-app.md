# Что видят агенты на телефоне

Торговые агенты работают почти полностью с телефона. Мобильное приложение SalesDoctor сделано для одной задачи: посещать клиентов, принимать заявки и отчитываться в офис — даже при плохом или отсутствующем интернете.

## Где взять приложение

Агенты скачивают **SalesDoctor** из Play Store или App Store. После установки они входят с теми же логином и паролем, которые вы создали в разделе [Добавление агентов](../getting-started/add-agents).

## Как выглядит день агента

| Шаг | Что агент делает на телефоне |
|------|----------------------------------|
| **1. Открыть маршрут** | Тапнуть по первому клиенту в сегодняшнем списке |
| **2. Прийти в магазин** | Приложение автоматически ловит GPS — визит начался |
| **3. Принять заявку** | Выбрать товары, указать количество — цены подставляются сами |
| **4. (Опционально) Аудит** | Сфотографировать полку, ответить на вопросы анкеты |
| **5. Закрыть визит** | Нажать **Готово**. Если визит не состоялся — выбрать причину |

Заявка уходит в офис сразу, если есть связь — или ставится в очередь и уходит, когда телефон вернётся в сеть.

## Что видите в офисе, пока они работают

На дашборде в реальном времени видно:

![Дашборд с прогрессом команды в реальном времени](/screens/guide/02-dashboard-home.png)

- Где каждый агент на карте
- Каких клиентов он посетил
- Кого пропустил (и по какой причине)
- Все заявки за сегодня

## Работа без интернета

Приложение хранит на телефоне:

- Маршрут агента
- Карточки клиентов и прайс-лист
- Каждый товар с фото и остатком
- Все принятые сегодня заявки

Поэтому даже без сигнала агент может продолжать принимать заявки. Всё синхронизируется автоматически, как только связь появится.

## Шаг 1 — Проверить синхронизацию (в офисе)

Никакой специальный экран не нужен — как только заявка агента дойдёт, она появится в `/orders/list`. Если ожидаемых заявок нет — телефон агента, скорее всего, вне зоны действия сети.

## Шаг 2 — Следите за KPI

Откройте `/dashboard/kpi`, чтобы увидеть месячный прогресс по каждому агенту:

![Месячный KPI-дашборд](/screens/guide/22-dashboard-kpi.png)

Полосы прогресса совпадают с тем, что агент видит на телефоне — он в реальном времени понимает, сколько ему осталось до цели.

## Советы

- **Один логин — одно устройство** — приложение держит сессию неделями.
- **Заряжайте телефон ночью** — GPS и мобильные данные сажают аккумулятор быстрее мессенджеров.
- **Обновляйте приложение** по запросу — важные новые функции приходят с ежемесячными обновлениями.
